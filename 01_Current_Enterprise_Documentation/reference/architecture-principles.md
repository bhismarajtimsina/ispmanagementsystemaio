# Architecture Principles

1. Domain authority is explicit.
2. Tenant isolation is structural and tested.
3. Device capabilities are driver declared.
4. Observed state carries source and freshness.
5. High-risk writes use controlled change workflows.
6. Passive fiber topology is explicit port/core connectivity, not map geometry.
7. Events are idempotent and auditable.
8. Unknown is not healthy.
9. UI cannot be the only validation layer.
10. History is preserved through revisions and retirement rather than destructive deletion.
