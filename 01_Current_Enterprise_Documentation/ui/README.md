# UI Mockups

This folder contains 47 generated FiberNet interface references covering dashboards, map/topology, closure/path views, OLT/PON, ONU/customer, TR-069, alarms, work orders, measurements/OTDR, Superadmin, ISP and reseller experiences.

Mockups define visual direction, not authoritative backend behavior. If a mockup conflicts with architecture or domain invariants, the written specification wins.
