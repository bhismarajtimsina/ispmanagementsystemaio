# Platform Acceptance Themes

- Tenant isolation for every API and export.
- Superadmin entitlements enforced server-side.
- RADIUS accounting/session control and retry safety.
- NMS stale-vs-down semantics.
- Driver capability rejection for unsupported writes.
- TR-069 task verification and unknown-model queue.
- Billing payment -> AAA restoration workflow.
- Alarm correlation groups downstream symptoms without deleting raw events.
- Offline field conflict does not use last-write-wins.
