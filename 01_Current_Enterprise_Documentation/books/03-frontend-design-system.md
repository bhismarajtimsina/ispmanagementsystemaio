# Frontend Design System

The FiberNet UI uses a desktop-first NOC workspace and an installable field PWA. Desktop follows a three-region pattern: persistent dark navigation, primary work canvas and optional context/detail panel.

## Visual language
- Navy navigation shell.
- CyberSathy blue primary actions.
- Green healthy/online.
- Orange degraded/warning.
- Red critical/down/damaged.
- Purple passive optical components.
- Gray unknown/stale/disabled.
- Icons, text and patterns accompany color.

## Screen states
Every screen must define loading, empty, success, partial, unknown, stale, warning, error, permission-denied, offline and conflict states.

## Shared components
GlobalSearch, TenantSwitcher, AssetStatus, EntityDrawer, VirtualizedTable, MapLayerControl, TopologyCanvas, TraceTimeline, LossLedger, OpticalResult, DiffViewer, AuditTimeline, WorkOrderCard, MetricCard, AlertBadge, PermissionGate and EntitlementGate.
