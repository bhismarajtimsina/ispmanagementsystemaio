# TR-069 / ACS

ACS is tenant isolated while using shared platform infrastructure. Device identity includes OUI, ProductClass, serial, manufacturer, hardware/software version and data model family. Unknown devices enter a classification queue.

FiberNet normalizes generic settings such as SSID or WAN configuration to model/firmware-specific TR-098/TR-181/vendor-extension parameter paths. Provisioning tasks have queued, waiting, sent, acknowledged, applying, verified, success, failed, expired and cancelled states.

A SetParameterValues response is not sufficient proof of success when read-back verification is available. Firmware jobs support canary rollout, staged percentages and automatic halt thresholds.
