# Reseller UI Book

Reseller menus are generated from entitlements and scope. Commercial-only resellers receive Customers, Billing, Wallet, Packages, PPPoE/Sessions, HotSpot/Vouchers, Tickets, Work Orders, Reports and Staff. Network-enabled resellers additionally receive Fiber Map, Network Topology, scoped Devices, OLTs, ONUs/ONTs, Links, IPAM and Alarms.

The reseller dashboard must show only assets and customers assigned to the reseller hierarchy or geographic/network scope. Fiber mapping remains the same canonical physical model as the ISP view; it is filtered, not copied.
